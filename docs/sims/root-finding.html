Solving f(x) = 0: bisection, false position, Newton

Most equations have no formula for their roots, so we approximate. Bisection halves a bracket (slow but sure), false position cuts it with a chord, and Newton's method rides tangent lines (blazing fast near a root, but it can run away). Type any function and watch the iterates close in.

Allowed: numbers, x, + − * / ^, parentheses, sin, cos, exp, ln, sqrt, pi, e. Example: exp(-x) - x, x^3 - 2*x - 5.

How to read this

Bisection needs a bracket [a, b] with f(a) and f(b) of opposite signs; a continuous f must then cross zero inside. Each step tests the midpoint and keeps the half whose ends still disagree in sign. After n steps the error is at most (b − a)/2ⁿ, so the number of steps for tolerance ε is known in advance: n > log₂((b − a)/ε). It is the continuous twin of binary search.

False position keeps a bracket too, but instead of the midpoint it takes the x-intercept of the chord through (a, f(a)) and (b, f(b)): xₙ = (a·f(b) − b·f(a)) / (f(b) − f(a)). It is to bisection what interpolation search is to binary search. Usually faster; sometimes one end gets stuck and it crawls.

Newton's method follows the tangent at xₙ down to the x-axis: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). Near a simple root the number of correct digits roughly doubles each step. It has no bracket, so a bad x₀ can cycle or diverge, and f′(xₙ) = 0 breaks it. The derivative here is computed exactly by automatic differentiation of your formula.

Table columns. Signs after aₙ and bₙ show the sign of f there (as in Levitin's traces); the last column is the bisection error bound or the step size |xₙ₊₁ − xₙ|.

Try this

  1. Book example, bisection on [0, 2], ε = 0.01. Predict the number of iterations first: log₂(2/0.01) ≈ 7.6, so 8. The 8th midpoint is x₈ = 1.3203125, with the root pinned between 1.3125 and 1.328125.
  2. Same function, Newton from x₀ = 2. The iterates 1.545455, 1.359615, 1.325801, 1.324719 hit six correct digits in 4 steps. Look at the race chart: the Newton curve plunges, bisection descends in a straight line (one bit per step).
  3. False position on the book example creeps up from the left while b = 2 never moves. Compare its 8th iterate (≈ 1.318) with bisection's (≈ 1.320). Now try the x^10 − 1 preset: which method wins?
  4. Break Newton. The trap preset bounces 0 → 1 → 0 → 1 forever; the runaway preset marches off to +∞ because the tangents keep pointing away from the root at 0. Change x₀ to 0.5 in each: does it recover?
  5. Newton for √D. With D = 2, x₀ = 1 and ε = 10⁻⁶: 1.5, 1.416667, 1.414216, 1.414214. This is the rule xₙ₊₁ = ½(xₙ + D/xₙ) that computers use for square roots.
