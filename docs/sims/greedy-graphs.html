Prim, Kruskal & Dijkstra

Three greedy algorithms on the same weighted graph. Prim and Kruskal build a Minimum Spanning Tree (MST) — the cheapest set of edges that connects everything. Dijkstra builds a Shortest-Path Tree (SPT) from one source. Each step grabs the locally best option and never takes it back.

How to read this

  • Labels under vertices follow Levitin's notation. Prim: b(a, 3) = the nearest tree vertex is a, by an edge of weight 3. Dijkstra: b(a, 3) = best path found so far arrives from a and has total length 3. (−, ∞) means “not reachable yet”.
  • The Tree vertices / Remaining vertices table grows one row per step, just like the textbook's trace tables. Red entries were just updated.
  • The priority queue lists fringe vertices by key; the greedy step always removes the top one.
  • Kruskal scans edges from lightest to heaviest. The union-find forest shows which vertices are already connected: two vertices with the same root are in the same tree, so an edge between them would close a cycle (drawn in purple) and is rejected.
  • At the end, dashed purple edges belong to the other tree (MST vs SPT) — handy for the “Prim vs Dijkstra” preset.
