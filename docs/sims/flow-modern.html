Maximum flow beyond augmenting paths

One network, three generations of maximum-flow algorithms. Edmonds–Karp runs a fresh Breadth-First Search (BFS) of the whole graph for every augmenting path. Dinic builds a layered level graph once per phase and pushes many paths through it with Depth-First Search (DFS). Push–relabel forgets about paths altogether: vertices hold excess flow and push it downhill.

What's happening

Same network, every algorithm

"Agrees" checks the flow value against a brute-force minimum cut (every split of the vertices into a source side and a sink side). Arc inspections counts every time an algorithm looks at a residual arc — BFS scans, DFS pointer moves, push attempts and relabel scans — so the methods can be compared on one scale.

Beyond: maximum flow in almost-linear time

In 2022, Li Chen, Rasmus Kyng, Yang P. Liu, Richard Peng, Maximilian Probst Gutenberg and Sushant Sachdeva showed that exact maximum flow — and minimum-cost flow — on a directed graph with m edges and polynomially bounded integer capacities and costs can be computed in m1+o(1) time: almost as fast as reading the input. Their algorithm does not augment along paths at all. It is an Interior-Point Method (IPM): it keeps a fractional flow strictly inside the feasible region and lowers a potential function, built from the cost and a barrier that keeps every edge away from its limits, in a sequence of m1+o(1) small steps. Each step sends flow around an approximate minimum-ratio cycle — the cycle with the best ratio of improvement (gradient) to barrier-weighted length. The breakthrough is a new dynamic graph data structure, built on low-stretch spanning trees and recursive graph decompositions, that finds and updates such a cycle in mo(1) amortized time while the edge weights keep changing. A nearly optimal fractional flow is then rounded to an exact integral one. The algorithm is randomized; van den Brand and coauthors made it deterministic in 2023. The mo(1) factors are huge, so practical codes still use push–relabel and augmenting-path methods like the ones above.

How to read this

  • Edges show flow/capacity. Blue edges carry flow (thicker when full). Orange = the augmenting path being used; a dashed purple edge is used backwards, cancelling flow. At the end, red dashed edges form the minimum cut, and green vertices are the source side.
  • Edmonds–Karp: the small number on each vertex is its BFS distance from the source in the residual graph. Every augmentation starts a new BFS.
  • Dinic: vertices are drawn in columns by level (BFS distance); unreachable vertices sit in the "∞" column. Only arcs from one level to the next (with room left) belong to the level graph; others are faded. Orange vertices are the current DFS path; a small orange ring at the start of an arc marks each vertex's current arc; grey vertices are dead ends.
  • Push–relabel: a vertex's height is its vertical position (gridlines are heights 0, 1, 2, …; the source sits at n). The yellow badge is its excess (flow in minus flow out). Flow may only move from height h to height h − 1. Relabel lifts a stuck vertex; the gap heuristic lifts a whole group at once.

Try this

  1. Phases vs augmentations. On the bipartite network, Edmonds–Karp needs 5 BFS runs for 4 augmentations. Dinic needs only 2 phases: the first finds 3 matching edges in one level graph (paths of 3 edges); the second finds the long rerouting path s→B→1⇠A→2⇠C→3⇠D→4→t, which shifts three earlier pairs at once.
  2. The shared prefix. Choose "Bad case for augmenting paths" with k = 8. Every augmenting path walks the same 4-edge chain, and Edmonds–Karp runs 9 full BFS scans: 321 arc inspections. Dinic finds all 8 paths in a single phase (81), and push–relabel moves all 8 units down the chain as one packet (100).
  3. Predict the level. In Dinic on the classic 6-vertex network, phase 1 uses paths of 3 edges. Before phase 2, guess the new sink level. (It must be longer: that is why Dinic has at most n − 1 phases.)
  4. Excess has to go home. In push–relabel on the classic network, the source pushes 5 units but only 3 reach the sink. Edge 4→3 only takes 1 unit, so vertex 4 is left with 2 extra units: watch it climb to height 7, above the source's height n = 6, so they can drain back.
  5. Mind the gap. Pick a random network with seed 18 and FIFO selection: 37 relabels. Turn on the gap heuristic: 13 relabels — the vertices that can no longer reach the sink jump straight to n + 1.
