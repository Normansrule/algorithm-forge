Karatsuba and Strassen: Multiply With Fewer Multiplications

School taught us that multiplying two n-digit numbers takes n² digit multiplications, and two n × n matrices take n³. Divide-and-conquer with one clever algebra trick beats both: 3 half-size products instead of 4 (Karatsuba), 7 half-size products instead of 8 (Strassen).

How to read this

Grade-school grid. Row j is one digit of b, column i is one digit of a; each cell is one digit multiplication. The grid has n × n cells, so there are n² of them.

Recursion tree. Each box is one call "x × y" on numbers with the digit count shown on the left. A call splits both numbers into a first half (a₁) and a second half (a₀) and calls itself on half-size numbers. Divide-and-conquer with 4 products makes 4 children per call, so 4^(log₂ n) = n² leaves: no savings. Karatsuba makes 3, so 3^(log₂ n) = n^(log₂ 3) ≈ n^1.585 leaves. Each leaf is one digit multiplication. Faded boxes are calls that haven't happened yet; green boxes have returned their product.

Karatsuba's trick. c₂ = a₁·b₁ and c₀ = a₀·b₀ are needed anyway. The middle term a₁·b₀ + a₀·b₁ equals (a₁ + a₀)(b₁ + b₀) − c₂ − c₀: one multiplication instead of two. If a sum like a₁ + a₀ carries into an extra digit, that digit is 0 or 1, so multiplying by it is just a copy, not a digit multiplication.

Strassen. Cells used as the first factor of the current product are yellow in A, second-factor cells are purple in B, and the C cell being assembled is blue.

Try this

  1. Levitin's warm-up is 23 × 14. Try it with Karatsuba: c₂ = 2·1 = 2, c₀ = 3·4 = 12, c₁ = 5·5 − 2 − 12 = 11, so 23 × 14 = 200 + 110 + 12 = 322 with 3 digit multiplications instead of 4.
  2. Enter two 8-digit numbers. Grade-school: 64 digit multiplications. Divide-and-conquer with 4 products: also 64. Karatsuba: 27. That's 3³ because 8 = 2³.
  3. Try 99 × 99 in Karatsuba. The sums 9 + 9 = 18 carry into a second digit; watch how the carry is handled without extra digit multiplications.
  4. Strassen, 2 × 2: check that each of C's four cells matches the ordinary row-times-column answer. 7 multiplications, but 18 additions instead of 4.
  5. Strassen, 4 × 4 as blocks: the seven block products are 2 × 2 matrix products, each done with Strassen again, for 7 × 7 = 49 multiplications instead of 4³ = 64.
