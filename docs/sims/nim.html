The Game of Nim

Two players take turns removing chips; whoever takes the last chip wins. Every position is either winning or losing for the player about to move, and a tiny formula tells you which. Learn it, then try to beat the computer.

How to read this

Winning (W) and losing (L) positions. A position is W for the player about to move if some move leaves the opponent in an L position. It is L if every move hands the opponent a W position. With 0 chips you can't move, so 0 is L. The analysis builds the table from 0 upward: that's decrease-and-conquer.

One pile strip. Each cell is a pile size n with its label (W green, L red) and n mod (m + 1) underneath. Arcs above show the moves being checked from the current n; arcs below show the winning move from every W position (like Levitin Fig. 4.16). L sits exactly where n mod (m + 1) = 0, and the winning move is to take n mod (m + 1) chips.

Many piles. Write each pile size in binary. The nim sum adds each column without carrying (odd number of 1s gives 1). The position is L exactly when the nim sum is all zeros. A winning move changes one pile so the nim sum becomes zero: find a pile with n ⊕ s < n and shrink it to n ⊕ s.

Playing. One pile: press a "take" button. Many piles: click a chip to remove it and every chip above it. The blue ring on the strip marks the game's current position.

Try this

  1. One pile, n = 10, m = 4, you move first, computer perfect. Can you win? (10 mod 5 = 0: you start in an L position, so a perfect opponent always wins.) Now let the computer move first.
  2. Predict the L positions for m = 3 before pressing play: 0, 4, 8, 12, … Check them on the strip.
  3. Levitin's many-pile example is 3, 4, 5. Its nim sum is 011 ⊕ 100 ⊕ 101 = 010, so the first player wins by taking 2 chips from the pile of 3. Verify with the hint button.
  4. Two equal piles (e.g. 6 6): the nim sum is 0. Play second and just copy your opponent's move on the other pile. Why does that always work?
  5. Set the computer to "randomly" and play from an L position. How quickly can you steer the game back to nim sum 0?
