# 📄 Cheat sheets

One-page references for exams and interviews. The same content, formatted for screen and print, is on the site:
**[normansrule.github.io/algorithm-forge/cheatsheet.html](https://normansrule.github.io/algorithm-forge/cheatsheet.html)**.

| Sheet | What's on it |
|---|---|
| [Asymptotic notation](asymptotics.md) | O, Ω and Θ definitions, the limit rule, L'Hôpital's rule, Stirling's formula, the basic efficiency classes with example algorithms |
| [Summations & recurrences](summations-and-recurrences.md) | Sum formulas and manipulation rules, the backward-substitution recipe with worked examples (including T(n) = T(n/2) + log n), the Master Theorem, and characteristic equations |
| [Design strategies](design-strategies.md) | A "which strategy fits my problem?" flowchart and a Forge Pseudocode template for each strategy |
| [Complexity table](complexity-table.md) | About 130 algorithms: best, average and worst time, space, stable or in-place, and the key idea |
| [Forge Pseudocode reference](pseudocode-reference.md) | The pseudocode language used in the lessons and run by the Arena, with every snippet tested against the engine |
